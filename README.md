# Fraud Detection Using Python

## Project Overview
A beginner-level transaction risk analysis project
using Python and Pandas.

## Tools Used
- Python
- Pandas
- Google Colab

## Features
- Transaction data analysis
- Rule-based risk classification
- High, Medium and Low risk categorisation

## Disclaimer
This project uses sample transaction data
and illustrative risk rules for learning purposes.
It does not confirm actual fraudulent transactions.
